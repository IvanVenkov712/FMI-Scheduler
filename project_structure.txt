Current project structure
=========================

README.md                 Project overview and documentation entrypoint
CONTRIBUTING.md           Development and validation guide
index.php                 HTTP front controller (repository root)
.htaccess                 Apache routing and public asset aliases
.env.example              Safe local configuration template
config/app.ini            Non-secret fallback configuration
config/routes.php         Registered HTTP endpoints

app/core/                 Framework bootstrap, routing, PDO, rendering, base classes
app/controllers/          HTTP actions, validation, sessions, role guards
app/services/             Business workflows, allocation, routing, import/export
app/repositories/         Prepared SQL and model mapping
app/models/               Mutable domain records
app/helpers/              Sessions, time, resource, delivery and sensitive-data helpers
app/logger/               Application file logger
app/exceptions/           Insert exception
app/views/                Server-rendered templates grouped by feature

public/css/style.css      Shared styling
public/js/app.js          Browser validation, drafts and JSON fetch helper
database/schema.sql       Initial MySQL schema (not a migration runner)
database/seed.sql         Current demo fixtures
database/*Insert.sql      Legacy standalone demo-user scripts
docker/                   Apache virtual host and startup script
Dockerfile                Apache/PHP image
docker-compose.yml        Local app and MySQL services
.gitlab-ci.yml            Runner-specific GitLab build/deploy pipeline (no tests)
.gitattributes            LF line endings for shell scripts

storage/                  Generated logs, exports and fallback sessions (Git-ignored)
docs/                     Setup, configuration, deployment, architecture,
                          components, HTTP, user guide, known issues, GitHub metadata
services.md               Current service contracts
IMPORT_EXPORT_FORMATS.md  Current CSV/XML/ASCII format reference

project_requirements.txt  Original Bulgarian assignment
project_specification.txt Proposed specification; includes unimplemented requirements
user-roles.txt            Pointer to current permissions documentation
admin_credentials.txt     Demo account reference

The earlier structure proposal listed files that do not exist in the implementation.
See docs/COMPONENTS.md for a linked inventory of every application component.
No Composer manifest, frontend package manifest, migration directory, or automated
test suite is currently included. The GitLab pipeline builds/deploys without tests.
